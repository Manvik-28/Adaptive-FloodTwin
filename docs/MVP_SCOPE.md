# Adaptive FloodTwin — MVP Scope

## Prototype Area

GRIET Campus

## Goal

Develop a micro-scale digital twin capable of:

1. Accepting rainfall scenarios
2. Modelling rainfall-driven surface water accumulation
3. Predicting flood depth and flood extent over time
4. Identifying unsafe areas
5. Generating safer evacuation routes
6. Visualizing the results on a web map
7. Validating predictions against available observations

## Core Pipeline

Rainfall
→ Runoff
→ Surface Flow
→ Water Accumulation
→ Flood Depth/Extent
→ Risk
→ Evacuation
→ Web Visualization

## MVP Technologies

- Python
- QGIS
- GeoPandas
- Rasterio
- NumPy/SciPy
- FastAPI
- React
- Leaflet
- NetworkX

## Out of Scope for MVP

- Full Hyderabad digital twin
- Full real-time sensor network
- Bluetooth mesh deployment
- Full 2D shallow-water solver
- Photorealistic 3D environment
- Complex AI prediction system
